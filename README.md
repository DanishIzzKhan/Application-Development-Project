# ISYGEAR – Bike Rental System

**TEAM NAME:** POP5

## Description

The Bike Rental System is a web-based application designed to improve the efficiency of bicycle rental operations by digitising and centralising processes that are normally handled manually by the stakeholder. The system aims to provide a convenient platform for customers to browse available bicycles, make rental bookings, and complete online payments, while enabling the seller to manage bicycles, monitor rental activities, and oversee transactions through an administrative dashboard.

The proposed system incorporates vehicle management, rental management, online payment, and administrator authentication to streamline daily operations and improve the organisation of rental records. In addition, GPS tracking devices installed on bicycles will support live location monitoring and location history recording. Features such as rental alerts and geofencing will further assist the seller in monitoring rental periods, identifying overdue rentals, and detecting when bicycles move beyond designated geographical boundaries.

The system will also incorporate AI-based predictive maintenance to help identify potential bicycle maintenance requirements based on usage patterns and reported issues.

Overall, the Bike Rental System aims to reduce reliance on manual processes, improve rental management efficiency, and enhance the experience for both customers and the seller.
